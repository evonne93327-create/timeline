# 時間軸

為虛構世界寫的年表工具。純前端、零依賴、可離線，資料存在你自己的瀏覽器裡。

> 姊妹專案：[世界觀架構工作台](https://github.com/evonne93327-create/world_2)（文檔與關係白板）。
> 兩邊的配色與互動刻意做成同一套，但目前資料是各自獨立的。

## 功能

- **多條時間軸**：主線、外傳、單一角色的生平，各自分開。
- **自由的時間寫法**：直接寫「舊曆340年 春」「第三紀元 12 年」，不必是真實日期。
- **排序值**：因為時間是自由文字，沒辦法直接比大小，所以另外用一個數字決定先後。新事件預設接在最後，可以按「從時間猜」自動填。數字之間留 10 的間隔，要插在中間時直接填個中間值就好，不必重編號。
- **七種分類色**：跟世界觀架構工作台同一組。
- **日間／夜間／跟隨系統**。
- **匯出／匯入 JSON**：這是唯一的備份手段，換裝置前記得做。匯入會取代全部資料，所以動手前會自動先下載一份目前的備份。
- **可安裝、可離線**（PWA）。
- **電腦版有自己的版面**：時間軸清單常駐在左側邊欄（切換一次點擊，不用開彈窗），標題與「新增事件」落在時間軸那一欄的正上方，按 <kbd>N</kbd> 直接新增。手機版維持頂部列 + 右下角浮動按鈕。分界在 900px。

## 資料存在哪裡

只在這台裝置的瀏覽器 `localStorage` 裡。**沒有雲端、沒有帳號、沒有伺服器。**
清除瀏覽器資料或換手機之前，請先用「設定 → 匯出備份」存成檔案。

## 開發

沒有建置步驟，沒有相依套件。用任何靜態伺服器打開就好：

```bash
python3 -m http.server 8800
# 然後開 http://127.0.0.1:8800
```

直接用 `file://` 開也能跑，只是 service worker 不會註冊（瀏覽器的限制）。

### 測試

`tests/browser.test.js` 是一支 Playwright 腳本，涵蓋事件的增刪改、排序規則、
多條時間軸的隔離、匯入的驗證、XSS、主題切換、手機返回鍵、以及 service worker
的 SHELL 有沒有跟實際檔案脫節。

```bash
python3 -m http.server 8800 &
node tests/browser.test.js
```

### 改動之後要記得

動到 `index.html` 引用的任何檔案時，把 `sw.js` 的 `VERSION` 往上加一號。
不加的話舊的快取不會被清掉，使用者會卡在舊版。

## 檔案結構

| 檔案 | 負責 |
|---|---|
| `js/state.js` | 分類色、常數、localStorage 的安全存取 |
| `js/storage.js` | 載入、存檔、存檔失敗的處理 |
| `js/ui.js` | 彈窗的鍵盤與焦點、手機返回鍵、浮出提示 |
| `js/timeline.js` | 時間軸的繪製與時間軸本身的增刪改 |
| `js/events.js` | 事件的增刪改 |
| `js/theme.js` | 日夜主題、設定總表 |
| `js/io.js` | 匯出、匯入與匯入的驗證 |
| `js/app.js` | 進入點、service worker 註冊 |
| `ui-tokens.css` | 所有顏色／字級／間距／圓角的來源 |
| `style.css` | 元件樣式（只引用上面的變數） |
